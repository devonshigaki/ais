# AIS Core (Autonomous Iteration System Engine)

Language-agnostic, AST-aware, self-healing code quality, risk, and architectural compliance framework.

## Capabilities
- **Universal Baseline Ratchet**: Prevents architectural and technical debt regressions across arbitrary metric dimensions.
- **RICE & Contextual Risk Scoring (CRS)**: Mathematical prioritization combining CVSS/EPSS reach vectors with engineering financial principal/interest.
- **Incremental Scanning**: Sub-second content-hash cache pipeline.
- **Quality Metrics**: Native Cyclomatic Complexity (CCN) and Maintainability Index (MI) engine.
- **Meta-Scanner Integrity**: Detects rewrite thrashing loops and disconnected/unwired rules.
- **Multi-Model Self-Healing Router**: Complexity-routed LLM auto-patching with provenance attribution.
